# iQOO Flow

Концепт смартфона iQOO для студентов и молодых специалистов. Работа для второго этапа технологического
чемпионата «Смарт Кон» iQOO 2026.

- Сайт: https://ivanfrolovskiy.github.io/iqoo-flow/
- Презентация: [PDF](assets/iqoo-flow-presentation.pdf), [онлайн-версия](https://ivanfrolovskiy.github.io/iqoo-flow/deck/)
- Видео с прокруткой сайта (1:23): [media/iqoo-flow-tour.mp4](media/iqoo-flow-tour.mp4)

![iQOO Flow](media/slide-01-title.png)

## Идея

У студента на одном телефоне и учёба, и подработка, и игры, поэтому телефон постоянно отвлекает. Режимы фокусировки
в Android есть, но заходить в настройки по нескольку раз в день неудобно. В iQOO Flow режимы вынесены на физический
тумблер на левой грани: вверх Игра, в середине Жизнь, вниз Фокус.

В Фокусе работает «Шумодав», языковая модель на 3 млрд параметров прямо на телефоне. Она показывает важные сообщения
сразу, остальные откладывает в сводку, расшифровывает голосовые. Ещё в телефоне есть резерв заряда: последние 10%
из 8 000 мА·ч не тратятся на игры и соцсети, их хватает на оплату, навигацию и звонки. Основа — iQOO 15R
(Snapdragon 8 Gen 5, игровой чип Q2), цена 59 990 ₽ за 12/256 ГБ.

Ключевой сценарий называется «Делу — время, потехе — час»: вечер студентки, у которой до полуночи сдача курсовой.

## Решения и допущения

Процессор такой же, как у iQOO 15R: Snapdragon 8 Gen 5. Флагманский 8 Elite Gen 5 здесь не нужен. Модель на 3 млрд параметров выдаёт
28 токенов в секунду уже на прошлом флагмане Snapdragon 8 Elite, а NPU в 8 Gen 5 по данным Qualcomm на 46% быстрее
предшественника. Для коротких сводок этого достаточно, а цена остаётся на уровне 15R. С флагманским чипом телефон
стоил бы около 80 тысяч, как iQOO 15.

Батарея 8 000 мА·ч. В Z11 стоит 9 020, но тумблеру нужно место в корпусе, и вес хотелось удержать около 208 г.

Памяти 12 ГБ. Модели в 4-битной квантизации нужно около 2 ГБ, а память в 2026 году заметно подорожала, так что
16 ГБ только подняли бы цену.

Себестоимость iQOO не публикует, поэтому структура цены на сайте — оценка по открытым данным Counterpoint и цене 15R.
Отдельно посчитан вариант, при котором память дорожает ещё на 40%: цена тогда выходит около 69 000 ₽.

Сценарий на сайте условный. Проверить идею предлагается пилотом на iQOO 15R и Z11 со ста студентами, до выпуска
нового корпуса.

## Что внутри

```
index.html            сайт
assets/css/main.css   стили
assets/js/            core.js (навигация и прокрутка по шагам), viz.js (графики), phone.js (макет телефона и экраны),
                      scenario.js (сценарий), demo.js (интерактивный тумблер), main.js (запуск), phone3d.js (собранная 3D-модель)
src/phone3d.js        исходник 3D-модели на three.js
assets/img/           рендеры модели и картинка для превью ссылки
assets/fonts/         Inter, Unbounded, JetBrains Mono
deck/                 презентация 16:9 в HTML, из неё печатается PDF
media/                слайды в PNG и видео
tools/                сборка 3D-модуля, рендеры, PDF, видео
```

## Как запустить

Сайт статический, его достаточно раздать любым веб-сервером:

```bash
python3 -m http.server 8791    # из корня репозитория, затем открыть http://localhost:8791
```

Пересборка картинок и файлов (нужны Node.js, Python с Playwright и Google Chrome, сервер на порту 8791):

```bash
./tools/build3d.sh               # three.js 0.186.0 + src/phone3d.js → assets/js/phone3d.js
python tools/render_posters.py   # рендеры модели
python tools/render_og.py        # картинка для превью ссылки
python tools/build_deck.py       # презентация в PDF и слайды в PNG
python tools/record_tour.py      # видео (нужен ffmpeg с libx264)
```

Если браузер не поддерживает WebGL, вместо 3D-модели показываются готовые рендеры. При включённой настройке
«уменьшить движение» анимации отключаются.
